# Add your books here

Create one folder per book inside `Books/`, then put the PDF inside that folder.

Example:

```text
Books/
  Book_01/
    Atomic_Habits.pdf
  Book_02/
    The_Alchemist.pdf
```

The website automatically finds every folder that contains a `.pdf` and uses the PDF filename as the book title.

Recommendation: keep PDF filenames clean, e.g. `Atomic_Habits.pdf` → `Atomic Habits`.
